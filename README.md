# TCC-G15 中文改造版

戴尔 G15 / Alienware 笔记本风扇与温度控制工具（AWCC 开源替代品）的中文增强版。

基于 [AlexIII/tcc-g15](https://github.com/AlexIII/tcc-g15) v1.6.4 二次开发，许可协议沿用 **GPL v3**。当前版本 **1.7.1-cn**。

## 下载

成品在 [Releases](https://github.com/dll315/tcc-g15-cn/releases/latest)，不以二进制形式提交进仓库：

| 文件 | 用途 |
|---|---|
| `tcc-g15-cn.exe` | 免安装单文件，右键「以管理员身份运行」 |
| `TCC-G15-cn-<版本号>-Setup.exe` | Inno Setup 安装器，装到用户目录 + 开始菜单/桌面快捷方式（快捷方式已带提权位） |

## 仓库内容

| 路径 | 内容 |
|---|---|
| `源码/` | 源代码、依赖清单、详细中文说明 `源码/README-CN.md` |
| `安装版/installer-cn.iss` | 安装器的 Inno Setup 脚本（路径相对自身，可复现构建） |
| `build.ps1` | 一键构建便携版 exe + 安装版 Setup |

## 功能

- 🌐 全面中文化 + 深蓝灰主题
- 📊 GPU / CPU 温度、转速实时仪表与托盘数字图标
- 📈 最近 5 分钟温度走势图
- 🎛️ **自动曲线模式**：自绘温度→风速折线，程序每秒按当前温度插值并下发（只在下发值变化时才写）
- 📝 CSV 温度日志（按天分文件，Excel 直接打开不乱码）
- 🛡️ **温度保护**：超阈值持续 8 秒自动切性能模式，降温 60 秒后恢复原模式
- ⌨️ 全局热键 `Ctrl+Alt+T` 显隐窗口、`F13`（G 键）切性能模式
- 🚀 开机自启（提权计划任务，登录时静默以管理员启动到托盘）

## 权限与开机自启

控制风扇要写戴尔的 WMI 方法，**必须有管理员权限**：普通权限下能读温度但控不了风扇。

- 程序启动时会自检权限，不足时提示「以管理员身份重启」
- 开机自启注册的是计划任务 `TCC_G15`（`RunLevel=HighestAvailable` + 登录触发），所以登录时不会弹 UAC；创建该任务需要在管理员权限下操作
- exe 自身不带 `requireAdministrator` 清单，因此**双击运行请右键 →「以管理员身份运行」**，或用安装版创建的快捷方式（已带提权位）

## 快速开始

下载上表的任一成品运行即可。从源码运行：

```
pip install -r 源码/requirements.txt
python 源码/src/tcc-g15.py
```

自己构建：

```
powershell -File build.ps1          # 加 -Debug 得到带控制台的调试版
```

## 支持的机型

Dell G15（5511/5515/5520/5525/5530/5535）、Alienware m16 R1、G3 3590，可能也支持其他戴尔 G 系列。

「CPU=风扇 0、GPU=风扇 1」是写死的机型假设，如果在别的机型上出现「CPU 滑条拧的是 GPU 风扇」，即为该假设不成立。

## 与原版共存

设置、开机自启任务名（`TCC_G15_CN`，原版的 `TCC_G15` 不被顶替）、安装包 `AppId` 都已与上游区分，可以同时装。但**不要同时运行**：两者每秒都在写同一套 AWCC 风扇接口，会互相抢控制权；`F13` 全局热键也只能被其中一个注册成功。详见 `源码/README-CN.md`。

## 免责声明

- 需要管理员权限（访问 WMI 接口）
- 风扇控制依赖 AWCC 的 WMI 组件，建议保留官方 AWCC
- 「手动」风速过低时 BIOS 会接管自动提速防过热（上游已知限制）
- 传感器读不到数值时，温度保护**按高温处理**（宁可误触发，不可漏触发）

详见 `源码/README-CN.md`。
